### ⛏️ MineOps — Offline-First Mining Operations System

**.NET 8 · ASP.NET Core · EF Core · SQLite + MySQL Sync**

Offline-first operations platform for remote mining sites. Captures data locally on SQLite and syncs to central MySQL via a queue-based background worker. Features 5-role identity, full audit trails, and interactive dashboards.

👉 [View Repository](https://github.com/siamewilliams/mineops)

**Stack:** C# · .NET 8 · ASP.NET Core · Entity Framework Core · SQLite · MySQL · Identity · FluentValidation · Serilog
