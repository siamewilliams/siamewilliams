# 🤖 Artificial Intelligence & Machine Learning Projects

## 🏠 3. Zambia House AI Agent — Multi-Model Agentic AI System

**Python · PyTorch · Ollama · Qwen 2.5 · FastAPI · Scikit-learn**

A locally hosted, multi-model AI agent designed to answer natural-language questions about Zambian house prices.

The system combines a trained PyTorch machine learning model with a locally hosted large language model. It uses a ReAct-style agent architecture to decide when to search the web, when to invoke the price prediction model, and how to generate a final response.

**Key features:**
- PyTorch MLP regression model for house price prediction.
- Complete model training and evaluation pipeline.
- Feature scaling and train/test separation to prevent data leakage.
- Adam optimiser and Mean Squared Error loss.
- MAE, RMSE, and R² model evaluation.
- Locally hosted Qwen model through Ollama.
- ReAct-style reasoning and tool calling.
- Autonomous web search using DuckDuckGo.
- Conversation memory and multi-turn context.
- FastAPI deployment with `/predict` and `/chat` endpoints.
- Fully local operation after model setup.

**Technologies:** Python · PyTorch · Ollama · Qwen · FastAPI · Scikit-learn · Pydantic · DuckDuckGo Search.

## 🛡️ 5. AI Biometric Identity Verification System

**Python · Flask · dlib · face_recognition · OpenCV · Laravel · MySQL**

An AI-powered biometric identity verification system developed for Rockview University's online examination platform to help prevent impersonation and account sharing.

The system captures a student's live webcam image and compares it with the profile photograph stored in the university system.

**Key features:**
- Python Flask REST API for facial verification.
- Live webcam image capture.
- Face comparison against registered student photographs.
- Hybrid HOG and CNN face-detection pipeline.
- Automatic fallback to CNN detection.
- Face-distance-based matching and confidence scoring.
- Student profile-photo enrollment workflow.
- Automatic detection of placeholder profile images.
- Laravel integration through REST communication.
- Camera permission and network error handling.
- Verification logging for auditing.
- Private microservice deployment using Gunicorn and systemd.

**Technologies:** Python · Flask · dlib · face_recognition · OpenCV · NumPy · Laravel · PHP · MySQL · JavaScript · WebRTC · Gunicorn · Linux.
